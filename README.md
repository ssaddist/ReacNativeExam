# BookShelf

Мобільний застосунок на React Native (Expo) для ведення особистої бібліотеки, пошуку книг через публічний каталог Open Library, відстеження прогресу читання та збереження нотаток.

## Функціонал

- Каталог та пошук книг через Open Library API (за назвою чи автором).
- Власні полиці: «Читаю», «Хочу прочитати», «Прочитано».
- Відстеження прогресу читання (сторінки, відсотки, прогрес-бар).
- Особисті нотатки з цитатами, сторінками та оцінками.
- Статистика читання, річні та місячні цілі.
- Світла та темна теми з локальним збереженням (AsyncStorage).

## Стек технологій

- React Native, Expo SDK 57, Expo Router
- TypeScript, React Native Reanimated
- Open Library API, AsyncStorage

## Як запустити

1. Встановіть залежності:
```bash
cd my-app
npm install
```

2. Запустіть сервер розробки:
```bash
npx expo start
```

3. Запуск на платформах:
- iOS: натисніть `i` або виконайте `npm run ios`
- Android: натисніть `a` або виконайте `npm run android`
- Web: натисніть `w` або виконайте `npm run web`
